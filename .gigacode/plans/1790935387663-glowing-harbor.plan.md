## Step 5: Create 10 test files in `tests/pages/`

### Test 1: `navigation.spec.ts`
- Verify all nav elements visible, clickable, correct hrefs
- Test "Get started" button navigation
- Validate Docs, API, GitHub, MCP, CLI links

### Test 2: `contentVerification.spec.ts`
- Main heading text verification
- Meta tags validation (title, og:title)
- Page title check
- Hero section content verification

### Test 3: `interactiveElements.spec.ts`
- Node.js button visibility and enabled state
- Search button opens overlay
- Keyboard shortcut Ctrl+K opens search
- Escape closes search

### Test 4: `searchFunctionality.spec.ts`
- Search overlay open/close
- Search returns results for query
- Multiple queries work without errors

### Test 5: `themeSwitching.spec.ts`
- Switch between system/light/dark themes
- Verify data-theme-choice attribute
- Screenshot comparison for light/dark modes

### Test 6: `linksValidation.spec.ts`
- All internal links have valid format
- External links point to expected domains
- All links have accessible text

### Test 7: `responsiveDesign.spec.ts`
- Desktop viewport (1920x1080) - no overflow
- Tablet viewport (768x1024) - layout adapts
- Mobile viewport (375x667) - content visible
- Screenshot comparison at different sizes

### Test 8: `docsPageNavigation.spec.ts`
- Navigate to /docs/intro
- Verify sidebar visible with links
- Verify page title and content
- Verify code blocks present
- Verify table of contents

- Verify API page content

### Test 9: `footerVerification.spec.ts`
- Footer is visible
- Footer links count and validation
- Social links (GitHub, Discord) present and correct
- Footer links have valid hrefs

### Test 10: `performanceAndAccessibility.spec.ts`
- Page load time < 3 seconds
- All images have alt attributes
- All interactive elements have aria-labels
- No console errors on page load
- Screenshot baseline comparison
